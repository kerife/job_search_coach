# Conversion receipt skip navigation

The private recruiter conversion receipt will expose its existing kicker as a
real keyboard skip link to `#main-content`, matching the other private HTML
artifacts. The link remains localized, noninteractive beyond navigation, and
does not change the receipt schema, data, privacy boundary, or action mapping.

Acceptance: both locales render an anchor with the localized kicker and the
existing main target; print hiding, CSP, deterministic rendering, and all
no-action/privacy assertions remain unchanged.
